Nicht verbunden

Du bist mit dem PC-Host (list_host.py) verbunden. Jedes Gerät, das diese Adresse öffnet, sieht dieselbe Liste; Änderungen erscheinen nach 1–2 Sekunden.

Mit PC-Host: Läuft auf dem PC list_host.py, öffne auf dem Handy dessen Adresse (z. B. http://192.168.x.x:8765) statt dieser Seite.

Gib auf jedem Gerät denselben Code ein (oder öffne den kopierten Link) und tippe auf „Verbinden“. Die Liste wird live abgeglichen, solange mindestens zwei Geräte gleichzeitig offen sind – sonst beim nächsten Verbinden. Wer den Code kennt, kann deine Liste sehen und ändern.
