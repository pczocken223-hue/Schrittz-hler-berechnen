Sprachbrücke

Ein Gespräch, zwei Sprachen, live übersetzt
Mikrofon blockiert: Diese Seite läuft über file://. Browser erlauben Mikrofonzugriff nur über https:// oder localhost. Am einfachsten: diese App bei GitHub Pages hosten (siehe README) und über die https://-Adresse öffnen.
Bereit — Mikrofon der sprechenden Person antippen

Noch kein Gespräch —
sobald jemand spricht, erscheint es hier.

Die Übersetzung wird mit der eingebauten Computerstimme der jeweiligen Sprache vorgelesen — nicht mit der Originalstimme der sprechenden Person.

Spracherkennung: Web Speech API (zuverlässig nur in Chrome/Edge) · Übersetzung: MyMemory Translation API (kostenlos, ohne Schlüssel) · Sprachausgabe: SpeechSynthesis API des Browsers.
